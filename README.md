# Eletrónica, Automação & Computadores

Protótipo de portal para divulgação e organização de recursos tecnológicos.

## Objetivo
Criar uma camada de navegação por cima dos repositórios existentes, sem alterar a estrutura dos projetos em andamento.

## Estrutura
- `index.html`
- `css/styles.css`
- `js/app.js`

## Organização
O portal agrega Eletrónica, Automação & Robótica, Computadores e Projetos, além de recursos como avaliações, sebentas, simuladores e projetos.

## Adicionar um recurso
Edite apenas o array `resources` em `js/app.js`.

## Publicação
Projeto estático, pronto para GitHub Pages. Não requer build ou framework.
